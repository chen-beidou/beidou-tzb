# 夸张表情库

## 定位

平时情绪照常写。遇到情绪高点(听到惊人消息 / 吃到神级美味 / 被拆穿 / 看到离谱一幕 / 赢了 / 输光了),要"脸上的戏放大"时,从本库取条目抄进分镜。**通用所有剧**,题材不限,哪部剧都能调。

定义(拍板版):夸张表情 = 脸上和身体的反应放大到"真人做不到、但一看就懂"的程度——观众不用听台词,光看脸就知道什么情绪。

和小剧场是一对:**表情库是零件,小剧场是用零件搭的一段戏**。写小剧场(beidou-xjc)时优先来本库取零件。

## 三条硬规矩(条条是铁)

1. **真人写实内夸张**:靠"反应幅度"夸张,不靠变卡通。脸不许变Q版、五官不许飞出去、不许贴漫画贴纸。漫画效果用真人拍法替,替法见库尾「漫画效果替代表」。
2. **一镜一个表情动作**:一个镜头只干一个表情动作(瞪大+后仰算一组连贯动作,可以;瞪大+喷水+弹起塞一镜,不行)。五官怎么动要写成物理动作,严禁写"很震惊""极度愤怒"这类空话。
3. **夸张但不出戏**:落点是"真人做不出来、但身体真会那么动",观众一眼懂又不觉得假。

## 用库四步

1. **定情绪家族**:这一刻是什么情绪?十族:震惊惊吓 / 慌张尴尬 / 暴怒 / 悲哭 / 狂喜 / 嫌弃恶心 / 馋爽破防 / 得意欠揍 / 恐惧崩溃 / 无语静默。
2. **查防重复账**:该集、该剧最近用过的条目不再用;同集同角色不重用同一条。
3. **取条目改写**:选最贴的一条,把角色名、道具、场合换成现剧的,写法骨架不动。每条自带"变",同条变体不连用。
4. **配镜头**:按库尾「镜头配合手法」给表情配运镜(急推脸/定格/慢放/环绕),节奏点落在表情最高点。

## 防重复三层保险

- **库大**:十族约百条,每条再带变体。
- **拆装**:条目可换零件——眼睛取A条、嘴取B条、身体取C条组合,不必整条搬。
- **轮换**:同角色同情绪连续出现,必须换条目或换组合。

## 边界(什么不归表情库管)

- 正常演技(哭戏、真挨打、普通受惊)——反应没超过真人,不走库。
- 换画风 / Q版 / 卡通化——另一回事,本库不干。
- 音效、字幕、后期贴纸——生成层面不管,只管镜头里演出来的。

## 自检(全过才算)

```
□ 不听台词,光看脸就知道情绪
□ 写的是五官/身体的物理动作,无"很/非常/极其+情绪词"空话
□ 一镜只一个表情动作
□ 真人写实,无卡通化、无贴纸化
□ 该集未重复使用同一条目(变体也算同条)
□ 夸张幅度与触发事件强度匹配(小事小夸张,大事大夸张)
```

成段产出照常走「分镜检查官」。
