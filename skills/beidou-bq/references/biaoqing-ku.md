# 夸张表情库(十族约百条)

用法:每条 = 【名】场合 / 写法 / 变(变体)。写法可直接抄进分镜,抄时把角色名、道具、场合换成现剧的。变体与正条算同一条目,连用要隔。

---

## 一、震惊 / 惊吓

1.【瞳孔地震】场合:听到惊人消息、看到不该看的。写法:双眼猛地瞪大,瞳孔瞬间缩成针尖,眉毛高高挑起,头向后一弹半寸,僵住半秒。变:①瞳孔缩小同时一颗冷汗滑过太阳穴 ②瞳孔地震加手中物品脱手落地。
2.【下巴脱臼】场合:看到超预期画面。写法:嘴缓缓张到最大,下巴像挂不住,喉结上下动了一下,半天发不出声。变:①张嘴同时手里的筷子垂到胸前 ②张到一半被人伸手把下巴推合上。
3.【石化定格】场合:当场被抓包。写法:全身瞬间定住,举着东西的胳膊停在半空,眼睛圆瞪不眨,一秒后只有眼珠缓缓挪动。变:①定格时头顶灯闪了一下 ②石化中脖子极慢地转过来。
4.【撞墙后退】场合:被迎面吓到。写法:连退三步,后背撞上墙,一只手在身后乱摸找支撑,嘴张开发不出声。变:①退到桌角带翻杯子 ②退半步才发现身后没墙,踉跄一下。
5.【手滑落物】场合:听到消息时手里有东西。写法:手指一根根松开,杯子从指缝滑落,目光始终没离开面前的人,杯子砸地才眨了一下眼。变:①落物换手机,屏幕朝下 ②落了一半被另一只手抢回。
6.【倒吸后仰】场合:意外突发。写法:上身猛地向后仰,喉咙里倒吸一口凉气,一只手抓住旁边人的胳膊。变:①后仰加椅子前腿翘起 ②倒吸气后憋成一声短促的"哈"。
7.【头皮发麻】场合:背后发凉。写法:双肩一缩,双手抱住自己胳膊搓了搓,后颈皮肤特写寒毛立起,他慢慢回头。变:①缩肩加原地小跳一下 ②搓胳膊搓到起鸡皮疙瘩。
8.【连环眨眼】场合:不敢相信眼前。写法:快速连眨三次眼,每次睁大都比上次更圆,嘴微微张开。变:①眨完伸手在眼前挥了一下 ②眨完改揉眼睛,揉完还在。
9.【捂嘴瞪眼】场合:听到炸裂八卦。写法:双手猛地捂住嘴,眼睛瞪到极限,从指缝里漏出一声短促抽气,头一点点转向旁边的人。变:①捂嘴改成捂耳朵 ②捂完又忍不住从指缝偷看。
10.【腿软扶桌】场合:被吓到站不稳。写法:膝盖一弯,一把扶住桌沿,扶桌的手背青筋凸起,半天直不起腰。变:①扶桌换扶人,把对方胳膊抓出指印 ②扶住后滑坐到椅子上。
11.【无声尖叫】场合:惊吓顶点。写法:嘴张到最大却没声音,双手插进头发里,身体抖了一下,眼睛瞪到流泪。变:①尖叫变破音的短促"啊" ②插头发改成捂住双眼,指缝分开一线。
12.【原地弹起】场合:坐着被吓。写法:从椅子上弹起来,椅子向后翻倒,手指着前方,嘴开合两下说不出话。变:①弹起带翻茶杯 ②弹起后跳上椅子。

## 二、慌张 / 尴尬

13.【瀑布汗】场合:谎要圆不住。写法:额角汗珠冒出,一颗接一颗滚过脸颊,抬手用袖子横着抹一把,汗更多了。变:①汗珠特写从鬓角滚到下巴 ②抹汗后手心也湿,在裤子上擦。
14.【眼神乱飘】场合:被追问。写法:目光四处躲,看左看右看天花板,就是不碰对方的眼睛,喉结上下滚。变:①最后干脆闭眼 ②眼神飘到对方身后装看风景。
15.【疯狂摆手】场合:被冤枉、被硬夸。写法:双手在胸前快速摆动,幅度越摆越大,头跟着摇,后背已经抵住墙。变:①摆手加连连后退 ②摆到一半自己先没底气,手停在半空。
16.【僵笑】场合:场面挂不住。写法:嘴角硬扯出一个笑,笑肌在抖,想收收不回,额头挤出褶子。变:①僵笑加眼角抽 ②僵笑到一半干咳一声试图解围。
17.【假咳遮掩】场合:说漏嘴。写法:猛咳两声,拿拳头挡嘴,咳到一半破音,耳根瞬间红透。变:①咳完抓起水杯猛灌 ②咳完假装接电话。
18.【脚趾抠地】场合:替别人尴尬。写法:(脚部特写)鞋尖在地砖上碾来碾去,脚趾蜷紧,重心从左脚倒到右脚。变:①加上原地小碎步蹭半圈 ②脚跟抬起又放下,反复。
19.【笑容裂开】场合:撑场面失败。写法:笑到一半表情冻住,嘴角一高一低,眼神开始向旁边人求救。变:①冻住后缓缓低头看自己的鞋 ②裂开加额角一滴汗滚落。
20.【手忙脚乱】场合:越掩饰越乱。写法:想扶杯子碰到碗,想拿碗又扫掉筷子,最后双手举在半空不敢碰任何东西。变:①乱到直接把托盘端翻 ②最后干脆把手背到身后。
21.【红到耳根】场合:被当众夸/戳穿心事。写法:脸颊先红,红晕漫过耳朵,低头用书挡住半张脸,露出的眼睛不敢看人。变:①红到脖子 ②用手扇风装热。
22.【小动作连环】场合:心虚。写法:摸鼻子、摸耳垂、扯衣角,三个动作十秒内挨个来一遍,越做越快。变:①加假笑点头 ②最后一个动作定格被当场拆穿。

## 三、暴怒

23.【青筋暴起】场合:被踩到底线。写法:太阳穴和脖颈青筋凸起,咬肌鼓起一个硬块,拳头攥到指节发白。变:①加拳头在桌面敲一下 ②青筋加呼吸拉长,鼻孔喷气。
24.【咬牙切齿】场合:忍着不发。写法:后槽牙咬得咯咯响,嘴角向下压,脸上肌肉一层层绷紧。变:①咬到腮帮鼓起又松开 ②咬牙加手指关节逐个掰响。
25.【捏瘪手中物】场合:怒而不发。写法:手里的塑料杯"咔"地瘪下去,汁水从指缝挤出来,他浑然不觉,目光钉着对方。变:①捏的是钢笔,笔杆弯了 ②捏完松手,东西直接碎在地上。
26.【揪领怼脸】场合:当面冲突。写法:一把揪住对方衣领拽到面前,两人的脸几乎贴上,鼻孔喷气,衣领被拽得变形。变:①拽起半寸离地 ②被第三人从背后抱住拉开。
27.【气到反笑】场合:荒唐到极点。写法:先是愣住,然后从鼻子里哼出一声笑,越笑肩膀抖得越凶,笑比哭难看。变:①笑完一句话不说转身就走 ②笑到一半猛地一拳砸在门框上。
28.【拍案起立】场合:当场爆发。写法:一巴掌拍在桌上,茶杯跳起,人跟着弹起来,椅子在地板上刮出刺响。变:①拍案加整摞文件滑落 ②拍完按住桌沿,手指抠进桌沿。
29.【瞪到眼红】场合:对峙。写法:盯着对方,眼白爬满血丝,眼眶泛红,一眨不眨,像下一秒要扑上去。变:①加拳头撑桌 ②眼红加下颌线绷直。
30.【一字一顿】场合:压抑的怒。写法:从牙缝里往外挤字,每说一个字下颌就绷一下,手指点着桌面,点一下说一个字。变:①最后一句突然拔高 ②说完猛地起身。
31.【胸口起伏】场合:怒气冲头顶。写法:胸膛大幅起伏,鼻翼张合,握拳的手背青筋一根根鼓起。变:①起伏三次后仰头闭眼 ②起伏中抬手看表,决定再等最后一分钟。
32.【掀桌】场合:彻底翻脸(大动作,用后记得写环境后果并延续)。写法:双手扣住桌沿猛地向上一掀,桌上的东西哗啦砸了一地,他站在原地喘粗气。变:①掀的是麻将桌,牌撒满地 ②掀到一半被死死压住没掀动,改成一把扫落一摞。

## 四、悲 / 哭过头

33.【泪如决堤】场合:消息坐实那一刻。写法:眼泪一下子涌出来,顺着下巴成串往下砸,抬手胡乱抹,越抹越多。变:①泪珠砸在手里的信纸上晕开 ②抹到脸都红了还在流。
34.【憋哭颤抖】场合:强撑体面。写法:嘴唇抿成一条线往下压,下巴在抖,眼泪在眼眶里打转就是不落,鼻尖红了。变:①憋到喉咙里发出一声闷哼 ②憋到对方一句安慰瞬间决堤。
35.【嚎啕打嗝】场合:情绪放闸。写法:张嘴大哭,哭到打嗝,一抽一抽,捶着胸口缓气。变:①捶胸口改成捶旁边人肩膀 ②打嗝把自己都逗破防,哭笑混合。
36.【泪水回流】场合:要强忍再开口。写法:眼泪涌到眼眶又硬生生憋回去,喉结滚动,再开口时声音劈了。变:①劈音后深吸一口气重来 ②憋回去的瞬间鼻涕泡吹出来,尴尬破功。
37.【无声流泪】场合:心死、听OS旁白(配OS按老规矩"嘴部闭合无口型")。写法:面无表情,眼泪却一颗接一颗往下掉,嘴唇闭紧,只有眼睛在动。变:①眼泪流进嘴角 ②流泪时手指微微蜷起。
38.【哭到滑跪】场合:天塌了。写法:双腿一软跪坐在地,双手垂在身侧,仰头张嘴却只有气声。变:①滑跪带地板摩擦声 ②跪坐后慢慢蜷成一团。
39.【抱头蹲下】场合:崩溃缓冲。写法:双手抱住头慢慢蹲下去,额头抵住膝盖,肩膀一耸一耸。变:①蹲到墙角 ②蹲下时帽子/东西掉在脚边没捡。
40.【笑中带泪】场合:悲喜交加。写法:一边笑一边掉眼泪,笑声越来越哑,最后笑不动了,脸垮下来。变:①笑着笑着改哭 ②哭着哭着又笑,循环两次。

## 五、狂喜

41.【拍桌大笑】场合:听到离谱的好消息。写法:一巴掌拍在桌上,整个人前仰后合,笑到拍腿,眼泪都笑出来。变:①笑到滑到椅子下 ②拍桌把茶水震洒。
42.【原地转圈】场合:得偿所愿。写法:张开手臂原地转了一圈,衣角飞起来,落地还在笑,头有点晕扶一下额头。变:①转两圈 ②转完直接躺到沙发上。
43.【蹦跳鼓掌】场合:孩子气的喜。写法:双脚同时离地蹦起,落地就拍手,拍手时还在原地小碎步。变:①蹦跳加原地挥拳 ②边蹦边把消息喊出来。
44.【笑出泪花】场合:好笑到顶。写法:嘴咧到耳根,眼角挤出泪花,抬手抹了一下又继续笑,抹完手还抖。变:①泪花加拍大腿 ②笑到打鸣式吸气。
45.【捂脸偷看】场合:害羞的喜。写法:双手捂住脸,从指缝里露出弯弯的眼睛,肩膀抖着偷笑,脚尖在地上画圈。变:①捂脸改成拿书挡 ②指缝偷看被抓个正着,捂得更紧。
46.【仰天大笑】场合:计谋得逞。写法:头向后仰,笑从胸腔里滚出来,一只手叉腰一只手指天,笑声在屋里回荡。变:①仰天笑加衣摆飞扬 ②笑着笑着被自己呛到咳嗽。
47.【语速飙快】场合:激动汇报。写法:兴奋到语速加倍,一句接一句不打磕巴,手在胸前不停比划,最后一句拖长音。变:①快到对方举手喊停 ②说漏嘴把惊喜提前泄露。
48.【抱人转圈】场合:狂喜找人分享。写法:一把抱住对方原地转两圈,对方双脚离地,两人都在笑。变:①转三圈踉跄扶墙 ②转完发现抱错人。
49.【点头如捣蒜】场合:连声应承。写法:头点得飞快,一下比一下幅度大,最后整条胳膊跟着挥,连说三个"好"。变:①点头加起身鞠躬 ②点到一半被泼冷水,脖子僵住。
50.【压不住嘴角】场合:要装镇定。写法:努力板着脸,嘴角一次次向上跑,用手背往下压嘴角,压一次弹回一次。变:①压到最后放弃,咧嘴笑出声 ②被上司看见,立刻清嗓子板回。

## 六、嫌弃 / 恶心

51.【嫌弃后仰】场合:闻到/看到不想接的。写法:上身向后仰到极限,下巴抬起,眼皮耷拉一半,嘴撇到一边。变:①后仰加抬手格挡 ②后仰到椅子打晃。
52.【白眼翻尽】场合:听到离谱发言。写法:眼睛缓缓翻上去只剩眼白,再缓缓转回来,全程面无表情。变:①翻完加一声长叹 ②翻到一半被叫住,眼珠先回来。
53.【干呕假吐】场合:真恶心到。写法:胃部一缩,弯腰干呕两声,直起身用手背抹嘴,脸还皱着。变:①干呕完漱口 ②干呕到旁边人跟着干呕。
54.【扇风驱味】场合:味道袭来。写法:手掌在鼻子前快速扇动,眉头拧成疙瘩,连连退步。变:①加用衣领捂鼻 ②扇完把责任物推远两米。
55.【鸡皮疙瘩】场合:肉麻到。写法:双手搓自己的胳膊,胳膊上鸡皮疙瘩清晰可见,缩着脖子抖了一下。变:①加起立走开两步 ②搓完互相拍打对方胳膊。
56.【两指拎起】场合:不得不碰脏物。写法:用拇指食指捏起东西的边角,胳膊伸到最直,脸偏向另一边,嘴撇着。变:①拎着东西用三根手指都嫌多 ②拎到垃圾桶上方松手后甩手三下。
57.【全身一抖】场合:被碰/被恶心到。写法:从头顶抖到脚底,像甩水一样抖了一下,龇牙咧嘴,双手在身上掸。变:①抖两下 ②抖完原地跺脚。
58.【嫌弃失语】场合:无语到极点。写法:嘴张开又合上,反复两次,最后只摇头,一言不发转身走。变:①摇头加抬手示意"别跟着我" ②失语后深呼吸再回头讲道理。

## 七、馋 / 爽·吃到神级美味(美食剧主力)

59.【定格睁眼】场合:咬下第一口。写法:咬下瞬间整个人僵住,双眼缓缓睁大,腮帮子还鼓着,眼眶慢慢泛红。变:①定格中筷子停在嘴边 ②睁眼后猛回头看食物,像怀疑它身份。
60.【闭眼三秒】场合:味道炸开。写法:闭上眼,眉头先是舒展,整个人向后靠,嘴角慢慢上扬,喉结咽了一下。变:①闭眼加摇头晃脑 ②闭眼时抬起一根手指,像品酒师。
61.【烫到哈气】场合:趁热吃。写法:烫得张嘴哈气,手在嘴前扇风,但筷子没停,又夹了一块。变:①哈气加跺脚 ②边哈气边含糊说"好吃"。
62.【塞满眯眼】场合:大口满足。写法:嘴里塞得鼓鼓的,眯起眼,肩膀放松下来,长长"呼——"出一口气。变:①两腮轮流鼓动 ②眯眼加幸福地晃头。
63.【仰头见底】场合:汤/面见底。写法:端起碗仰头,喉结连滚几下,放下碗时碗底干干净净,他还把碗沿又转着舔了一圈。变:①舔碗被看见,僵住 ②见底后把碗举起来看光。
64.【嘬指舔筷】场合:回味。写法:手指一根根嘬过,嘬完盯着空盘愣两秒,眼神开始找锅里还有没有。变:①筷子头也含进嘴里 ②嘬完直接端锅。
65.【对盘发呆】场合:吃完了不舍得。写法:吃完盯着空盘发呆,用筷子头刮盘底的酱汁,刮一下舔一下,像在打扫现场。变:①刮完把盘子举起来照 ②发呆中被服务员收走盘子,伸手想拦。
66.【勾魂飘移】场合:被香味牵走。写法:鼻子动了动,人像被线牵着,踮着脚一步一步飘向厨房,眼睛已经直了。变:①飘移加吞咽口水特写 ②飘到锅边被热气熏醒,擦口水。
67.【长叹松弛】场合:咽下去那一秒。写法:肩膀整个垮下来,头向后仰靠住椅背,四肢摊开,像跑完马拉松。变:①叹气加拍肚子两下 ②松弛到从椅子上出溜下去半截。
68.【眼中冒星】场合:食物上桌瞬间。写法:睁大眼睛,眼睛亮得反光,双手捧脸,小腿在桌子底下飞快打拍,身体前倾到快贴上桌。变:①冒星加吞口水声 ②前倾把桌布都拽歪。

## 八、得意 / 欠揍

69.【冷笑上扬】场合:稳操胜券。写法:嘴角只挑起一边,缓缓上扬,眼皮半垂,手指转着笔。变:①转笔换转车钥匙 ②冷笑加抬眼看向对手一秒。
70.【挑眉贱笑】场合:得逞欠揍。写法:一边眉毛挑起,嘴角咧开,眼睛眯成缝,头微微一点两下。变:①加打响指 ②贱笑加比划"你懂的"手势。
71.【叉腰仰头】场合:赢了庆祝。写法:双手叉腰,下巴抬到看不见脖子,用鼻孔看人,胸口挺起。变:①叉腰加原地踱步 ②仰头到帽子/头发都后翻。
72.【弹灰嫌弃】场合:以强凌弱式得瑟。写法:伸两根手指在对方肩膀上弹了弹灰,弹完吹一下指尖,再看回自己的指甲。变:①弹灰加掸自己袖口 ②弹完把对方证件/照片还回去。
73.【原地起舞】场合:私下庆祝。写法:得意到小幅度扭两下,自己给自己打响指,对空气比了个耶,转角差点撞人,秒变严肃。变:①跳舞加对镜自照 ②起舞被撞见后假装系鞋带。
74.【镜前自夸】场合:臭美。写法:对着镜子理头发,侧头看侧面,冲镜子里的自己点了一下头,顺手把衣领立起又按下。变:①加wink ②自信出门撞上玻璃门。
75.【慢动作过场】场合:高光时刻。写法:故意放慢脚步从人群中走过,抬手挥了挥,嘴角压不住,周围人纷纷让路回头。变:①慢走加风衣扬起 ②慢走到一半踩到香蕉皮式打滑(可接崩人设)。
76.【秒垮脸】场合:得意被拆穿。写法:正得意着,被人一句话点破,笑容像被抽掉,整张脸垮下来只要半秒,嘴角一寸一寸往下掉。变:①垮脸加定格 ②垮完强行续笑,续不上。

## 九、恐惧 / 崩溃

77.【面无人色】场合:见到真正怕的东西。写法:血色从脸上褪下去,嘴唇发白,身体不受控地向后蹭,手在身后撑地。变:①蹭到退无可退贴住墙 ②后退带翻身后凳子。
78.【牙关打颤】场合:又冷又怕。写法:上下牙"咯咯"相撞,说一个字抖一下,抱着自己胳膊缩成一团。变:①颤音说话含糊不清 ②牙齿打颤加原地小跳取暖。
79.【失焦瘫坐】场合:精神击穿。写法:双眼失焦,瞳孔放大,膝盖一屈直接坐在地上,手还保持着伸出去的姿势。变:①瘫坐加眼泪无声掉 ②瘫坐后被人架起,脚尖拖地。
80.【腿抖成筛】场合:硬着头皮上。写法:双腿抖得站不住,扶着墙也抖,鞋跟在地上磕出细碎的响。变:①抖到单膝跪地撑住 ②抖着往前挪,挪一步退半步。
81.【冷汗湿背】场合:事后后怕(背部拍法)。写法:衬衫后背湿出一大片,颜色深一块浅一块,贴在背上,他拉了拉衣角遮掩。变:①湿背加手抖递文件 ②被发现湿背,自己都没察觉。
82.【声音劈叉】场合:强装镇定失败。写法:说话说到一半声音突然拔高破音,清了下嗓子再开口还是抖的,自己都咳嗽掩饰。变:①劈叉加瞪大眼清嗓 ②连续两句劈叉,索性闭嘴点头。
83.【崩溃大笑】场合:荒诞压垮。写法:笑声越来越大,笑到最后变调,笑着笑着眼泪下来了,分不清是笑是哭。变:①大笑加蹲下抱头 ②笑到岔气扶墙。
84.【抱头缩团】场合:极度惊恐。写法:双手死死抱住头,整个人缩进墙角,头埋到看不见脸,只剩肩膀在抖。变:①缩团加把帽檐拉低 ②抖着从指缝偷看,又赶紧埋回去。

## 十、无语 / 静默

85.【长久盯视】场合:被冒犯后的沉默。写法:一言不发盯着对方,十秒不眨眼,对方眼神躲到哪里,他的视线就跟到哪里。变:①盯视加缓缓放下手中杯子 ②盯完只说一个字。
86.【缓缓转头】场合:听到离谱指令。写法:头极慢地转过去,眼神从下往上扫对方一遍,什么也没说,扫完把东西轻轻放回原位。变:①转头加脖颈"咔"一声音效点 ②扫完转身就走。
87.【扶额深呼吸】场合:带不动队友。写法:一只手按住额头,闭眼,胸口缓缓起伏一次,再睁眼时眼里没光了。变:①扶额改揉太阳穴 ②呼吸三次才睁眼。
88.【嘴角抽搐】场合:想发作又不能。写法:嘴角左右各抽一下,想说话又咽回去,重复两次,最后闭眼长出一口气。变:①抽搐加太阳穴跳动 ②最后改口"算了",两个字咬得很重。
89.【看傻子眼神】场合:对方自信满满说错话。写法:歪着头,眼皮半耷,嘴角向下,盯着对方足有三秒,轻轻"啧"了一声。变:①啧完摇头 ②三秒里眨了一次很慢的眨眼。
90.【默默转身】场合:懒得理会。写法:什么都没说,转身就走,脚步不快,背影写满"不想理",门在身后合上不重不轻。变:①走前把对方给的东西轻轻放下 ②走两步又回头补一句。
91.【叹到塌肩】场合:认命。写法:一口气从胸腔里叹出来,肩膀跟着塌下去,头也垂下去,连手指都松了。变:①叹完拍拍自己脸振作 ②叹气声拖长成哼歌。
92.【面色一沉】场合:笑意收敛的压迫感。写法:说笑到一半,脸上的笑一层层收干净,额前阴影压住双眼,屋里像降了三度。变:①沉脸加把杯子轻轻放下 ②沉到一半被电话打断,又瞬间挂回笑容。

## 镜头配合手法(给表情配运镜)

1. **急推脸**:触发瞬间镜头猛推到面部特写——震惊/恐惧首选。
2. **急拉回**:小剧场/幻想结束切回现实用,拉回即是"出戏"。
3. **定格一拍**:表情最高点画面停住一秒,节奏点。
4. **慢放**:丢人/高光瞬间放慢,配合内心OS(嘴部闭合无口型)。
5. **环绕半圈**:升天式狂喜/幻境,镜头绕角色半圈。
6. **低机位仰拍**:角色发力/压迫感的表情,仰拍加码。
7. **过肩怼脸**:两人对峙,从一人肩后怼另一人脸。
8. **静默一拍**:全段突然无声半秒,只留表情在动。
9. **快切三连**:同一表情三个不同角度快切,越来越夸张。
10. **跟摇**:角色从A震惊到B,镜头跟着摇过去接力。

## 组合规则(拆装零件)

条目不必整条搬,可按"眼 / 嘴 / 头颈 / 手 / 腿身"五个部位拆开拼:
- 眼取【瞳孔地震】+ 嘴取【僵笑】+ 手取【疯狂摆手】= 慌到极点又强装镇定。
- 拼装后仍守一镜一动作:一个镜头只演一组连贯动作。
- 拼出来的新写法按第2步查账:该集没用过才可用。
