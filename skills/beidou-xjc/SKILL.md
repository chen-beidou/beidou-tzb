# 小剧场

## 定位

小剧场是"切出去演"的装置:正片演到某个瞬间,突然切出去,单独演一小段夸张搞笑的戏,把这一刻放大给观众看,演完切回正片,剧情一秒没耽误。

- **片尾彩蛋只是其中一种放法**。一集可以放很多个:开头钩子、正片中间、两场戏之间、片尾,都能放。
- **美食只是用户举的例子,不是主场**:任何剧、任何场景,只要有触发点就能切。常见触发场景:吃到神级美味、打完一场、看到离谱一幕、听到天价或惊人消息、误会被拆穿、开箱开盒揭晓、门后第一次露面、反差当场暴露、输赢揭晓瞬间……数不完,凡情绪最冲的瞬间都行。
- 示范(美食剧):客人咬下一口的瞬间 → 切幻境小剧场 → 夸张表现"好吃" → 切回现实含泪竖大拇指。换成"打赢一拳后切吐槽""开箱开出假货切推理现场",一模一样的用法。
- **通用所有题材**:美食、玄幻打戏、萌宝、都市、悬疑、宫斗、职场、乡村……都能切。
- 和表情库的关系:**beidou-bq 表情库是零件,小剧场是用零件搭的一段戏**,夸张表现优先从表情库取。

## 定死的规矩(定义 canon,2026-09-12 拍板)

1. **有触发点**:必须挂在剧情的某个瞬间上(吃到/看到/听到/说完/打完/拆穿),不凭空插段。
2. **切出去独立成段**:进、出小剧场都要有明确的"切"的痕迹(画面一黑/定格一拍/白闪),观众一眼知道"这是小剧场"。
3. **10~30秒**:一般 15 秒一镜 ~ 30 秒三镜,不抢正片的戏。
4. **搞笑向**:必须好笑或过瘾;不许做成严肃回忆杀、硬广口播。
5. **删了不影响正片**:小剧场是加料,拿掉它剧情照样通顺。
6. **素材来自当下剧情**:每段必须至少含一个"**本场独有物**"——只属于这一场戏的道具/台词/人设反差/前情梗。这是不重复的根。

## 工作流程

```
找触发点 → 选形态 → 挖本场独有梗 → 取夸张表情 → 写段 → 自检 → 交检查官
```

### 第一步:找触发点

正片里情绪最冲的瞬间就是触发点。高频触发点(如美食剧"每吃一口"都触发)必须登记轮换,排法见 [references/xjc-shoufa.md](references/xjc-shoufa.md) 的「高频触发点轮换表」。

### 第二步:选形态

五种形态见 [references/xjc-shoufa.md](references/xjc-shoufa.md):脑补幻想式 / 吐槽式 / 重演式 / 对镜头式 / 平行小剧场式,共五十多种玩法。**同一集内形态尽量错开,同一形态不许连用;同一触发点连续出现,玩法必须换。**

### 第三步:挖本场独有梗

翻这一场戏:有什么道具只在场?哪句台词刚说完?谁的人设此刻反差最大?前情哪笔账还没翻?至少挖出一个,写进小剧场当主料。

### 第四步:取夸张表情

到 beidou-bq 表情库按情绪取条目,守其三条硬规矩(真人写实内夸张 / 一镜一动作 / 写物理动作)。

### 第五步:写段

- 格式**沿用该集分镜现有结构**,不自造(照动作包同款规矩)。小剧场单独成 Clip 或成段,标题行尾加标记「｜小剧场」便于辨认;标记只写标题行,不进提示词正文。
- 进、出小剧场的"切"要有具体拍法(定格一拍/白闪/画面一黑半秒),写进镜头正文。
- 内心 OS/VO 按老规矩标"嘴部闭合无口型"。
- 台词是新写的(小剧场本来就是加料),但三条红线:**不新增人物、道具、设定、剧情事实;人设口癖守该剧 canon;不毁人设**。项目另有台词纪律的,听项目的。

### 第六步:自检(全过才算)

```
□ 挂在触发点上,进出有"切"的痕迹
□ 10~30秒,拿掉它正片照样通顺
□ 单独看能笑(懂正片梗更好笑)
□ 含至少一个"本场独有物"
□ 与本集/本项目已有小剧场:形态不同、核心梗不同
□ 夸张表情来自 beidou-bq 库且一镜一动作
□ 不新增人物/道具/设定,人设台词守canon
□ 正文无草稿痕迹
```

### 第七步:交检查官

成段分镜照常走「分镜检查官」全流程(生成与检查绑定),修到合格为止。

## 输出

- **插进已有分镜**:存成独立文件「第X集_小剧场.md」放该项目分镜同目录,原分镜不动,用户点头后再插进正文。文件开头写清**插入位置**(不许写行号;用 Ctrl+F 能搜到的字定位:插在搜到的某段之后、下一段标题之前)和**前后衔接对齐了哪些点**。
- **做新分镜时顺手写**:直接写进该集分镜,标题行尾带「｜小剧场」标记。

## 防重复四层保险

1. **素材锁定**:每段必含"本场独有物",剧情不重样,料就不重样。
2. **形态轮换**:同集多个小剧场形态错开、同形态不连用;同一触发点反复出现(美食剧顿顿吃)按轮换表排,连三次主料不重样。
3. **查账**:动手前先翻该剧/该集已有小剧场,列出已用形态+核心梗,这些不再用。
4. **库大**:手法库五形态五十多种玩法只供取骨,肉(道具台词人设梗)永远现挖。
