## 范例一|美食剧·脑补幻想式(15秒,插在正片咬下食物处)

- **触发点**:客人咬下牛肉丸的瞬间
- **形态**:A-1 美食幻境
- **本场独有物**:前情埋的"外婆的味道"这句台词
- **表情库条目**:【定格睁眼】【眼中冒星】【闭眼三秒】

```
镜头1(0-3秒)[平视·固定,无]:特写:竹签叉起油亮的牛肉丸递到嘴边,客人张嘴咬下,忽然僵住,双眼缓缓睁大,腮帮子还鼓着(表情库【定格睁眼】)
镜头2(3-9秒)[平视·环绕半圈·慢,无]:小剧场-幻境:客人原地缓缓离地升空,周身泛起金光,身后灶台升起金色麦浪,锅中食材悬浮起舞排成星河(表情库【眼中冒星】)
镜头3(9-12秒)[平视·急推至面部·快,无]:幻境顶端,客人闭眼,嘴角咧到最大,一颗泪从眼角甩出去(表情库【闭眼三秒】变体①)
镜头4(12-15秒)[平视·急拉回·快,无]:画面一黑半秒切回:客人整个人扑在桌上,含泪竖起大拇指,嘴里含糊:"外婆……就是这个味!"
```

**不重复要点**:主料是"外婆的味道"(本场独有);表情库三条互不重复;下次再触发"吃到"必须换形态。

## 范例二|玄幻打戏·吐槽式(15秒,插在战斗结束摆pose处)

- **触发点**:主角一拳打飞巨兽后背对镜头耍帅
- **形态**:B-19 一句话拆台 + B-20 算账吐槽
- **本场独有物**:同伴手里碎成两半的盾牌
- **表情库条目**:【嘴角抽搐】

```
镜头1(0-4秒)[低机位仰拍·固定,无]:主角背对镜头收拳,烟尘从拳边滚过,保持收势不动
镜头2(4-7秒)[平视·急摇·快,无]:镜头摇到同伴:他举着碎成两半的盾牌,嘴角左右各抽一下,想说话又咽回去(表情库【嘴角抽搐】)
镜头3(7-12秒)[平视·缓推·中,无]:同伴:"盾,三万八。你那一拳,帅,免费的。"说罢转身就走,背影写满"不想理"
镜头4(12-15秒)[低机位仰拍·固定,无]:主角保持pose,视线瞟向同伴背影半秒,清了清嗓子,快步跟上
```

**不重复要点**:主料是"盾牌造价"(本场道具);用后盾牌破碎状态在正片延续,不修复。

## 范例三|萌宝家庭·对镜头式(30秒,插在闯祸被追处)

- **触发点**:萌宝把大人手机藏进米缸,大人翻箱倒柜
- **形态**:D-40 播报式
- **本场独有物**:米缸 + 大人绕客厅的圈数
- **表情库条目**:【压不住嘴角】

```
镜头1(0-4秒)[平视·固定,无]:客厅鸡飞狗跳,大人翻遍沙发抱枕,萌宝坐在小板凳上,双手背在身后
镜头2(4-8秒)[平视·缓推·中,无]:画面定格一拍白闪切出:萌宝面前的玩具桌摆成"主播台",他清清嗓子,努力板着脸,嘴角一次次向上跑(表情库【压不住嘴角】)
镜头3(8-16秒)[平视·固定,无]:萌宝(播报腔):"本台消息:某大人找手机已绕客厅七圈,沙发垫伤亡四只。"镜头外传来更大声的翻找声
镜头4(16-24秒)[平视·急推至面部·快,无]:萌宝对镜头竖起食指抵住嘴唇,比了个"嘘",眼睛弯成月牙
镜头5(24-30秒)[平视·急拉回·快,无]:画面一黑半秒切回:大人掀开米缸盖子,萌宝脚底抹油开溜,笑声跑出画面
```

**不重复要点**:主料是米缸和圈数(本场独有);播报腔只此一次,下次触发改用形态E宠物视角。

## 范例四|都市·平行小剧场(15秒,插在反派放完狠话离场处)

- **触发点**:反派在会议室放完狠话,摔门而出
- **形态**:E-49 反派视角
- **本场独有物**:狠话原文 + 西装内袋的压瘪三明治
- **表情库条目**:【牙关打颤】变体

```
镜头1(0-4秒)[平视·固定,无]:会议室:反派一字一顿放完狠话,抓起外套摔门而出,门框上的灰簌簌往下掉
镜头2(4-7秒)[平视·缓推·中,无]:切出:地下车库,反派靠住自己的车门,长长吐出一口气,胸口还在大幅起伏
镜头3(7-12秒)[平视·固定,无]:他抬手看表,手在抖;从西装内袋掏出一个压瘪的三明治,就着风大口咬下,牙关咯咯打颤,边嚼边骂:"吓死我了……"(表情库【牙关打颤】变体)
镜头4(12-15秒)[平视·急拉回·快,无]:画面一黑半秒切回:会议室里众人面面相觑,桌上文件还在轻轻晃
```

**不重复要点**:主料是压瘪三明治(本场道具)+狠话反差(本场台词);平行视角全剧错开用。
