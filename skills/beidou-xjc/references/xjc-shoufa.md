# 小剧场手法库(五形态五十多玩法)

用法:玩法只供取骨(结构),肉必须现挖——每段小剧场的主料永远从当下剧情里来(本场独有物)。同一集内形态不重;同一触发点连续出现按「高频触发点轮换表」排。

---

## 形态A 脑补幻想式(角色脑内画面,最出大片感)

1. **美食幻境** — 咬下一口瞬间整个人升天/发光,环境跟着变金碧辉煌。美食剧标配;例:一口面汤,人浮起半米,汤碗在脚下放大成一片湖。
2. **妈妈的味道** — 一口下去闪回童年灶台,切回现实已泪流满面。例:咬下糖糕,闪回外婆的柴火灶。
3. **小天使小恶魔** — 肩上两个自己在吵架,越吵越离谱。例:减肥夜,天使劝沙拉,恶魔端炸鸡。
4. **成功幻想** — 想象赢的样子(领奖/打脸/求婚成功),镜头一转现实先摔一跤。
5. **灾难化脑补** — 把小事脑补成世界末日。例:迟到三分钟→被开除→流落街头→住桥洞,一气呵成。
6. **物品拟人** — 食物/道具开口说话。例:锅里最后一块红烧肉冲他喊"别犹豫了,吃我"。
7. **钻进去看** — 视角缩小钻进机器/锅里,里面是另一个世界。例:钻进洗衣机,里面是风暴海洋。
8. **偶像剧滤镜** — 脑补自己帅到发光,镜头一转现实很挫。
9. **恐怖片脑补** — 开冰箱/开门用恐怖片拍法,里面只是剩菜。
10. **武侠脑补** — 夹菜/抢座/抢外卖拍成华山论剑,慢动作配重剑相击。
11. **宫斗脑补** — 办公室/家族群聊拍成后宫交锋,步步惊心。
12. **科幻脑补** — 修灯泡拍成修飞船,扳手当光剑,火花四溅。
13. **自带解说** — 脑内给自己配体育解说,越燃越好笑。例:"他出场了!历史第38次减肥!"
14. **游戏界面** — 头顶弹出经验条/任务完成/连击数/成就徽章。
15. **选择困难分身** — 两个自己当场对决,拔刀/石头剪刀布。
16. **推理现场** — 吃出异物/看到异常,拍成刑侦现场,放大镜+慢镜回放。
17. **升天满足** — 全身发光缓缓离地,周围环境金光普照,仙乐(可无音效靠画面)。
18. **预演未来** — 眼前快放"如果这么做会怎样",三种结局全翻车,最后一个比一个惨。

## 形态B 吐槽式(直接对荒诞处开火)

19. **一句话拆台** — 别人吹得震天响,他淡淡一句戳破。例:"这就是你说的'轻伤'?绷带都缠成粽子了。"
20. **算账吐槽** — 现场算账,把离谱量化。例:"这一口,我三天工资。"
21. **静默白眼** — 不说话,一个白眼加转身,胜过千言。
22. **旁白毒舌** — 画外音替观众吐槽,又准又损(OS按"嘴部闭合无口型")。
23. **连环对怼** — 两人你一句我一句,一句比一句狠,结尾一方卡壳。
24. **自嘲** — 自己先躺平认领,比谁嘲讽都狠。例:"对,全公司最惨,奖状我领了。"
25. **对物吐槽** — 冲着道具单独发火。例:对着磨断的鞋带开了三分钟教育大会。
26. **翻旧账** — 一口气报出三笔旧账,节奏像报菜名,报完拍桌。
27. **称呼梗** — 气到把对方称呼升级/叫全。例:"王。建。国。你给我过来。"
28. **假装没听见** — 对方音量拉满,他摇头:"啊?你说什么?"连来三次。
29. **假客套** — 笑着说狠话,句句带刀还带"您"。例:"您可真是我的再生父母,这债就免了吧?"
30. **一秒认怂** — 吼到一半看清对方/对方身后,立刻改口猛夸。

## 形态C 重演式(把刚才的事换个拍法重放)

31. **慢放+OS** — 刚才的丢人瞬间慢放,内心OS哀嚎。
32. **倒放** — 事件倒着放,越倒越荒诞。
33. **换视角重演** — 从受害方/路人视角重放同一件事,反差揭底。
34. **换风格重演** — 买菜拍成谍战交接,遛狗拍成西部决斗,站位走位全套。
35. **逐帧回放** — 按暂停逐帧拆解自己的丢人动作,一帧一崩溃。
36. **录音回放** — 放出刚才的丢人台词,本人捂耳扑向录音设备。
37. **照片定格连环** — 三张定格照配三行内心吐槽,一张比一张没眼看。
38. **多机位回放** — 同一次摔跤给三个机位,一个比一个清晰,最后一机位是主人公正脸。

## 形态D 对镜头式(打破第四面墙)

39. **采访式** — 话筒怼脸问角色,一本正经胡说。例:"请问您减肥成功的秘诀?""还没开始。"
40. **播报式** — 一本正经播报离谱数据。例:"本台消息:该客本周好吃到哭9次,餐厅已备好纸巾。"
41. **预告玩梗** — 预告下集,全是空镜头加大话,一个正片镜头没有。
42. **求关注桥段** — 角色不想营业,被画外音押着说"点关注不迷路",全程生无可恋脸。
43. **幕后揭底** — 镜头一拉,刚才的"神迹"是这么做出来的。例:大侠转身在片场点外卖。
44. **敲第四面墙** — 冲观众使眼色/叹气/指指自己太阳穴,一句话不说。
45. **观众视角** — 镜头当人,被角色拉进画面当面质问:"你也觉得我错了吧?"
46. **主持人总结** — 角色像新闻主播一样总结本场事故,身后画面还在回放黑历史。
47. **颁奖式** — 给本场最丢人瞬间颁奖,本人上台领奖,发表感言时台下是当事人。
48. **反向悬念** — 一本正经"下集更精彩",配的是最不像的下集画面。

## 形态E 平行小剧场(镜头外同一时刻的另一边)

49. **反派视角** — 反派回巢卸下狠劲,委屈/抠门/给花浇水,白天的凶是演的。
50. **道具视角** — 从那把被摔的椅子/那口锅看全场,带感情独白。
51. **路人视角** — 路人围观主角们发疯,默默绕道,一脸"又一个"。
52. **宠物视角** — 猫/狗看俩人类吵架,翻个白眼走开,尾巴扫掉桌上的东西。
53. **系统视角** — 玄幻金手指/系统在内心吐槽雇主(配OS"嘴部闭合无口型")。
54. **配角加班视角** — 主角们谈完正事潇洒离去,配角默默收拾残局/填坑/背锅。
55. **邻居视角** — 隔壁住户对墙壁叹气,习以为常地戴上耳塞,墙皮都在震。
56. **官方吐槽** — 画外音对整场戏的套路/穿帮直接开嘲,一集一个梗不重样。

## 高频触发点轮换表(同一触发点连用怎么排)

以美食剧"吃到"为例,实际排时按剧情现选,原则:**连三次内,主料不重+表情库条目不重;同一形态不许连用超过一次(第1、2次都用脑补式时必须换玩法,第3次换形态)。**

```
第1次:形态A-1 美食幻境(升天发光)         — 立标杆,先给最炸的
第2次:形态A-2 妈妈的味道(闪回)          — 同形态只许连一次,第二次就换主料
第3次:形态B 算账吐槽(同桌:这是他本周第5次流泪)
第4次:形态D 播报式(小剧场播报:该客本周好吃到哭9次)
第5次:形态E 道具视角(那碗汤的独白:终于被喝到见底)
第6次:形态A 换全新幻境(如科幻脑补:味道像飞船点火)
循环往复,主料永远取自当下这碗/这一场。
```

其他高频触发点同理:打戏"每打完一场"、萌宝"每闯一次祸"、都市"每次听到报价"、悬疑"每开一次箱"、宫斗"每次听到消息",都照这个排法轮换。
